# 8.1 Independent Review Gates and Failed Review Classification

_Part of [Yggdrasil — Architecture (arc42)](../README.md) · [§8](README.md)._

Every execution-chain Subtask (Mimir or Brokk) receives a dedicated Heimdall review, and every Orchestration Task ends at a Final Review Gate whose first dispatch is a fresh Heimdall session; Kvasir and Bragi outputs receive no dedicated review and the gate is their backstop (`agents/odin-autonomous.md:237-265`). Review mechanics: verdicts are authoritative and never re-reviewed; verification is against ground truth, not self-report; the baseline is pinned in the brief; a review passes iff its verdict line is `PASS` or `PASS-WITH-NOTES` (`:245-248`). Failure handling is the Failed Review Classification — execution defect → fix loop; plan-level mismatch → Kvasir first; three-round cap with Kvasir consult after two; disputed finding → verify and one reconsideration; baseline error → correct and reconsider (`:267-279`). Every packaged workflow inherits these rules without restating them (`:177`; `scripts/odin-generator/shared-body.template.md:150`). Instances: the Architecture workflow's context and persistence reviews (`skills/architecture/odin-architecture-workflow/SKILL.md:63-70`), the TDD workflow's context, package, integration, and commit reviews (`skills/engineering/odin-tdd-workflow/SKILL.md:68-77`), and the Memory pipelines' write reviews (`skills/memories/odin-memory-system/SKILL.md:57`). Two nodes are unreviewed by explicit design rather than by the Kvasir/Bragi default: the Architecture workflow's drafting step and the TDD workflow's plan step, each gated by a checkpoint and by the reviews of what consumes it (ADR-0016, ADR-0021). The commit review is the one gate whose artifact is already irreversible when it runs: a `BLOCKED` there is cleared by a corrective commit, never by rewriting history — one resume for a staging omission, otherwise the run ends with the review path named (`skills/engineering/odin-tdd-workflow/SKILL.md:66`; `skills/engineering/heimdall-tdd-review/SKILL.md:129`).
