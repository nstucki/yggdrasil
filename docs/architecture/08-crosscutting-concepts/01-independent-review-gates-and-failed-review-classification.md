# 8.1 Independent Review Gates and Failed Review Classification

_Part of [Yggdrasil — Architecture (arc42)](../README.md) · [§8](README.md)._

Every execution-chain Subtask (Mimir or Brokk) receives a dedicated Heimdall review, and every Orchestration Task ends at a Final Review Gate whose first dispatch is a fresh Heimdall session; Kvasir and Bragi outputs receive no dedicated review and the gate is their backstop (`agents/odin-autonomous.md:237-265`). Review mechanics: verdicts are authoritative and never re-reviewed; verification is against ground truth, not self-report; the baseline is pinned in the brief; a review passes iff its verdict line is `PASS` or `PASS-WITH-NOTES` (`:245-248`). Failure handling is the Failed Review Classification — execution defect → fix loop; plan-level mismatch → Kvasir first; three-round cap with Kvasir consult after two; disputed finding → verify and one reconsideration; baseline error → correct and reconsider (`:267-279`). Every packaged workflow inherits these rules without restating them (`:177`); the Architecture workflow's design review and the Memory pipelines' write reviews are instances (`skills/architecture/odin-architecture-workflow/SKILL.md:118, 160`; `skills/memories/odin-memory-system/SKILL.md:57`).
