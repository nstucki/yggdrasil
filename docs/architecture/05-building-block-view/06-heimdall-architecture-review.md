# 5.1.5 Blackbox `heimdall-architecture-review` (new dedicated review skill)

_Part of [Architecture Workflow (Yggdrasil) — Architecture (arc42)](../README.md) · [§5](README.md)._

- **Purpose / responsibility:** the single owner of every architecture review checklist — the arc42 document in both modes, and the persisted directory — so that no checklist for an architecture artifact lives in the engineering-review skill.
- **Provided interface:**
  - Brief lines: `Focus: context | scaffold | document | persistence` (exactly one; missing → ask the requesting agent). With `Focus: document`, also `Mode: decide-new | document-existing` (absent ⇒ `decide-new`). **R4 adds `context`** (ADR-0013).
  - Verdict grammar (first line of the review Workfile): `Verdict: <PASS | PASS-WITH-NOTES | BLOCKED> — focus=<context|scaffold|document|persistence>, mode=<decide-new|document-existing|n/a>, artifact=<path>, <one-clause reason>`.
  - Review Workfile names: `NN-review-context-architecture-<area>.md` (context), `NN-review-architecture-scaffold.md` (scaffold), `NN-review-architecture.md` (document), `NN-review-architecture-persistence.md` (persistence).
  - `Focus: context` (R4; standing review of the `mimir-architecture-context` session): scope declaration present (system/subsystem or objective footprint, exclusions with reasons); output contract complete **against the architecture-context contract in §5.1.8** — area map, entry points and call paths, boundary interfaces quoted verbatim, embodied cross-cutting concepts, existing architecture and decision-record inventory, dependencies, current-state view or its omission line, not-examined list; every finding proven (`path:line` or command + output); fact-rich, framing-poor (recommendation or target-state content is BLOCKED); resolve at least two proofs yourself, chosen from module boundaries and boundary interfaces; documentation facts resolve — named document/record paths exist, and the reported shape and highest record number **agree with the scaffold step's `Scaffold result` when both exist** (a disagreement is a finding on whichever is wrong, verified live); `[UNVERIFIED]` ≤ 25 %; diagram elements trace to findings. **Not** checked here: test infrastructure, baseline run, behavior characterization — those belong to the engineering shape. BLOCKED on: an unresolvable proof; framing content; missing scope declaration; a §5-load-bearing interface summarized rather than quoted; unverified share > 25 %.
  - **Common step 1 gains a standing-doctrine item (R5, R-21):** "the producing session wrote only what its role may write — a Brokk session created or changed files in the target project and **no** Workfile; a Kvasir or Mimir session wrote **only** Workfiles and **no** project file. Verify with `git status --short` (project) and a listing of the task directory (workspace). A violation is blocking in every Focus." This is the check whose absence let the R2 scaffold design pass four reviews.
  - `Focus: scaffold` (R5 — reviews a **target-project directory**, not a Workfile; ≤ 8 items): (1) `git diff --name-status <baseline>` against the target shows **only additions** — for `structure=created`: exactly **thirteen** files — a top `README.md` plus the twelve `NN-<section>/README.md` index stubs, §9's being the decision-log variant of a section index (an empty log table in place of a Documents table), nothing else; for `verified`: **no change**; for `extended`: only the missing section folders' indices. (2) Top index reads `Status: Scaffolded`, carries `Date`, `Document scope`, `Mode … (source …)` equal to the brief, a Sections table with every row `pending`, and a Change Log with one `scaffolded` row (created only). (3) Each section index carries the H1 `# N. <Title>`, the backlink, the one-line Yggdrasil section description, and `_Pending — not yet drafted_`; **no** topic document, **no** section prose, **no** `arc42 guidance §N` text anywhere under the target (grep = 0). (4) Shape re-derived by the identity rules of 5.1.13 (folder layout, flat legacy, single file, non-arc42, none) and equal to the result line. (5) `next-adr` re-derived across every decision directory found. (6) `document-scope` follows from the shape (`none` → seed; else update delta). (7) The workspace gained **no file** from this session (common item). (8) The seed-collision rule was honored: no pre-existing `README.md` whose H1 is not this document's was overwritten. BLOCKED on: any project file modified or deleted; any content or guidance text under the target; wrong shape/`next-adr`/`document-scope`; a Workfile written by the session; a top index not at `Status: Scaffolded` after `created`.
  - `Focus: document` **R5 additions (both modes):** header carries `Scaffold: <target> (structure: …)` equal to the brief's result line and `Document scope` equal to its `document-scope` (mismatch blocking — the persistence step trusts this header); **Appendix D layout map present and total** — every heading under each `## N.` appears in exactly one row, each row follows one of exactly three patterns — a topic document (`NN-<section>/NN-<slug>.md`, two-digit ordinal contiguous from `01` within the folder, kebab slug from the root heading, promotion = root depth − 1), a decision record (`09-architecture-decisions/NNNN-<slug>.md`, promotion 2), or **the single `## 9.` log row** (`09-architecture-decisions/README.md`, promotion `—`, rows appended to the generated index — a named exception, and the only row whose target is an index); any other target or promotion is blocking; a section with a single document is named `01-<section-slug>.md`; splits satisfy the split rule (≥ 3 independently consulted units) — a split below it is a note, a heading in two rows or in none is blocking; decision records map to `09-architecture-decisions/NNNN-<slug>.md` continuing from `next-adr`; **no `arc42 guidance §N` text and no attribution notice** in the Workfile (the drafter never had guidance to delete — a notice present is attribution by reflex, a note; guidance present is blocking as before). Then the mode checklists as delivered:
  - `Focus: document`, `Mode: decide-new`: the checklist currently at `heimdall-engineering-review/SKILL.md` § Focus: architecture (lines 81–95), moved verbatim — header/status/section-scope/existing-document lines, quality goals drive §4/§9/§10, honest pruning, attribution iff guidance survives, ≥2 options per ADR, log↔records one-to-one, §5 paths opened and interfaces test-precise, §6 error paths, Appendix B package fields and `Package check:` consistency, Appendix C exactly-once ownership, update-delta consistency, gaps reported; BLOCKED set unchanged.
  - `Focus: document`, `Mode: document-existing`: the shared items (header, pruning, attribution, log↔records, §5 paths, §6, gaps, update-delta) plus: every §5 block cites a path present in the context Workfile; no proposal language in §4/§9 (BLOCKED if a §9 row proposes a change); each ADR carries `Kind: as-is` with evidence paths; Appendices B/C carry `_Not applicable — document-existing mode_`; `- **Mode:**` header present and matches the brief (BLOCKED if absent or mismatched). The ≥2-options, Appendix B, and Appendix C items do not apply.
  - `Focus: persistence` (R5 — rewritten for the folder layout; inputs add the `Scaffold result` line and the reviewed Workfile's Appendix D): (a) **Scaffold precondition.** The target held the scaffolded structure before this session (identity rule of 5.1.13) with top index `Status: Scaffolded` (seed) or `Accepted` (update delta); a persistence that created folders itself, or ran against an unscaffolded target, is blocking. (b) **Map ⇔ tree.** `git diff --name-status <baseline>` lists exactly: the topic documents Appendix D names for the `included=` sections (created or replaced), those sections' `README.md` indices (regenerated), `09-architecture-decisions/README.md` (rows appended only), the new `NNNN-<slug>.md` records, and the top `README.md` (regenerated, one Change Log row appended). Nothing else changed; **no topic document exists that the map does not name**, and a previously persisted topic document the map no longer names was **not deleted** — it is listed in the section index under "superseded documents" (persistence never deletes). (c) **Promotion.** Open at least two topic documents and one record beside their Workfile sources: each document's H1 is its root heading promoted by exactly `depth − 1`, its body promoted by the same distance, the backlink line second; records `# ADR-NNNN` with parts at `##`. (d) **Omitted sections** are index-only folders whose index carries the marker verbatim; a persisted `_Not affected by this change_` is blocking. (e) **Indices.** Each regenerated section index lists exactly the folder's documents in ordinal order with their root headings; the top index's Sections table shows state (`filled | omitted | pending`), document count, last-updated; `Status: Scaffolded → Accepted` on first fill; Change Log grew by one row, prior rows byte-identical. (f) **Decision records**: promotion by two, `Accepted` iff ratified, log↔file both ways relative to `09-architecture-decisions/README.md` (or the project's own ADR directory). (g) **Attribution**: no `arc42 guidance §N` text under the target — if any is found, a notice must accompany it in that file (blocking otherwise). (h) **Manifest ⇔ diff**, action vocabulary as before plus `index regenerated`. (i) **Migration** (flat→folder or single-file→folder) only with cited user direction; the pre-migration files are moved (`git mv`, history preserved), not re-created, and the Change Log records `migrated from <shape>`. (j) Planning material (B, C, **D**) not persisted; process metadata not promoted. No test-suite item.
  - Common steps 0–2 (control line, pin baseline, common checks, review Workfile order) mirror the engineering-review skill's, restated here because a skill must be self-contained (C-1 five sections + Boundaries). The skill names no foreign slug (C-3): it says "the scaffold session", "the drafting step", "the persistence manifest".
