# 5.1.11 Blackbox `brokk-arc42-template` (renamed from `kvasir-arc42-template`; scaffolds)

_Part of [Architecture Workflow (Yggdrasil) — Architecture (arc42)](../README.md) · [§5](README.md)._

- **R5 — Modified (ADR-0016, ADR-0017, ADR-0020); the R2 description below is superseded where it says "Workfile":**
  - **Purpose:** own the arc42 **structure reference** (section/subsection numbering and titles, Yggdrasil one-line section descriptions; the CC BY-SA § Skeleton guidance is retained in the skill as reference material for maintainers and reviewers and is **never written anywhere** by this skill) and **scaffold the folder layout of 5.1.13 in the target project**. The seam is unchanged — Brokk classifies shape and resolves `next-adr` here, so Kvasir never does — but the output is an Artifact skeleton, not a Workfile (C-16).
  - **Workflow:** (1) read the I-5 brief (`mode`, `source`, `location`, `objective`; a missing `mode`/`source` → ask). (2) Resolve the target by the search order and classify with the identity rules of 5.1.13 — `directory` (folder layout), `flat directory (legacy)`, `legacy single file`, `non-arc42`, `none`; apply the seed-collision rule (a `README.md` whose H1 is not `… — Architecture (arc42)` → scaffold into `docs/architecture/arc42/`, report the fallback). (3) Resolve `next-adr` across every decision directory found. (4) **Act on the target:** `none` → create the top `README.md` (`Status: Scaffolded`, `Date`, `Document scope: seed`, `Mode … (source …)`, Sections table all `pending`, Change Log row `scaffolded`), and twelve section folders each holding only its index stub (H1, backlink, one-line description, `_Pending — not yet drafted_`; for §9 the stub is the decision-log variant — an empty log table instead of a Documents table) — **thirteen files in total** → `structure=created`; `directory` with all folders → write nothing → `verified`; `directory` missing folders → add only those → `extended`; every other shape → write nothing → `verified`, with `migration required` appended for `flat directory (legacy)` and `legacy single file`. (5) Report the `Scaffold result` line and every candidate/decision directory found. **Boundaries:** never a topic document, a section body, a record, or a byte of arc42 guidance in the target; never a Workfile; never modify or delete an existing project file (extension adds, only).
  - **Location:** `skills/architecture/brokk-arc42-template/SKILL.md` — Purpose (lines 41–55), When to Use (57–63), Workflow (65–126), Quality Criteria, Anti-Patterns rewritten; § Skeleton (157–776) and the `Attribution and license` block **unchanged**; a "Structure reference" table (twelve sections, subsections, one-line descriptions) added above § Skeleton as the text the stubs are generated from. Slug **kept** (a rename would ripple through `LICENSES/CC-BY-SA-4.0-arc42.txt` lines 6/8/66, README, and a deployed-copy sweep for no behavioral gain — option recorded in ADR-0016).
  - **Fulfilled AC:** AC-4, AC-6, AC-15 (jointly — the scaffold is the precondition of every persisted Artifact).
