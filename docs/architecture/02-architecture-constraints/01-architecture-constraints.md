# 2. Architecture Constraints

_Part of [Yggdrasil — Architecture (arc42)](../README.md) · [§2](README.md)._

Constraints the system is built under, each evidenced. C1–C10 stood before this revision (C10 updated to the document's current state); C11–C16 are the user-ratified constraints of this revision, carried in the brief as fixed — none is a choice this document weighs.

| # | Constraint | Kind | Evidence |
| --- | --- | --- | --- |
| C1 | **OpenCode is the only runtime.** Yggdrasil has no executable of its own; every behavior is a system prompt, a skill, or a command interpreted by OpenCode, and installation requires `~/.config/opencode/` | Technical | `README.md:103`; `README.md:113-141` |
| C2 | **Pure Markdown / YAML / Bash, portable to macOS bash 3.2.** No compiled code and no package manager; generators are `cat` and `sed` concatenation; validator avoids bash-4-only features | Technical | `scripts/README.md:153-160`; `scripts/validate.sh:56-57` |
| C3 | **Authorization is the agent frontmatter permission block.** Every capability boundary is expressed as OpenCode `permission:` rules (`"*": deny` then explicit allows) | Technical / security | `agents/odin-autonomous.md:6-19`; `agents/mimir.md:6-68`; `agents/brokk.md:6-64` |
| C4 | **All files under `agents/` are generated and never edited directly.** Validator Check 4 fails on any byte difference from generator output | Organizational | `scripts/README.md:70, 105-107`; `scripts/validate.sh:338-431` |
| C5 | **Skills must carry the five required sections in fixed order and a `name:` matching their directory slug**; skill descriptions may not name agents | Convention (validated) | `scripts/README.md:67-72` (Checks 1–3, 6) |
| C6 | **Subagent prompts and skills may not reference other agents by name** (subagent isolation). Consequence for this revision: `agents/eitri.md` may not mention Brokk even though the README myth pairs them | Convention (validated) | `scripts/validate.sh:433-496` (Check 5) |
| C7 | **Workfiles live only under `.yggdrasil-workspace/<yyyymmdd>-<task-slug>-<xx>/`, rooted at the session working directory, gitignored, referenced by relative paths** | Convention | `agents/odin-autonomous.md:78-80`; `agents/brokk.md:90` |
| C8 | **Workfiles are created and extended with the `edit` tool; the `write` tool is not used** because it is documented to hang in this environment | Environmental (asserted in prompts) | `scripts/subagent-generator/tooling.fragment.md:1-7` |
| C9 | **Yggdrasil Memory is written only by the Remember/Dream/Forget pipelines**, never as an Artifact, never containing secrets | Governance | `agents/odin-autonomous.md:86-88`; `skills/memories/odin-memory-system/SKILL.md:31, 57-61` |
| C10 | **The architecture document lives at `docs/architecture/` in arc42 directory shape**, all twelve sections filled and eight decision records accepted at the time of this revision | Documentation | `docs/architecture/README.md:1-36`; `docs/architecture/09-architecture-decisions/README.md:9-18` |
| C11 | **The new specialist is named Eitri** — the dwarven master-smith, brother of Brokkr, already foreshadowed in the README's Brokk narrative | User-ratified (brief) | `README.md:61-63`; brief § User-ratified design constraints |

| C13 | **Permission baseline is minimal**: write markdown within the Yggdrasil Workspace, write image files to any directory, read the Yggdrasil Workspace. | C14 | **The image model is configurable per agent without code changes, file-based** — no interactive prompts, no CLI, and no mechanism that requires editing this repository after install | User-ratified (brief); `01-requirements.md` § Out of Scope item 5, NFR 6 | brief; `01-requirements.md` |
